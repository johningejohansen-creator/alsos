# alsos.no – backup

Statisk kopi av www.alsos.no (Tannlege Alsos AS), hentet 16. september 2026 fra Telenors hjemmesidetjeneste og publisert med GitHub Pages.

- Sider: `index.html`, `behandlinger.php.html`, `om-oss.php.html`
- Kontaktskjemaet sender fortsatt til Yola/Telenors skjematjeneste, og Google-kartet bruker Telenors API-nøkkel. Begge kan slutte å virke når Telenor-abonnementet avsluttes.
- Ny kopi: kjør `python3 ../speil.py` fra mappen over.
